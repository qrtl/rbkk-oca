To configure this module:

1.  Go to *Settings \> Users & Companies \> Groups*
2.  Find and select the "Own Manager: Manage own attendance records" group
3.  Add users to this group to allow them to create and edit their own attendance records
4.  Go to *Attendances \> Disallowed Fields*
5.  Add fields that users in the "Own Manager" group should NOT be able to edit
    The overtime_status field is disallowed by default
