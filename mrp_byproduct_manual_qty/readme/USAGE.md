To use this module:

1.  Go to *Manufacturing \> Manufacturing Orders* and open or create one
    with byproducts on its BoM.
2.  Confirm the manufacturing order.
3.  On the *By-Products* tab, edit the *Quantity* of any byproduct line.
4.  Mark the manufacturing order as done.

The byproduct quantity entered manually is preserved on completion,
instead of being replaced by the value computed from the BoM.
